# gyomu

나의 교무수첩으로 연결해 주는 주소예요. `uzzint.github.io/gyomu/2026`처럼 뒤에 무엇을 붙여도 같은 교무수첩(구글 앱스스크립트 웹 앱)으로 이동해요.
교무수첩 자료는 이 저장소에 없고, 열 때 내 구글 계정으로 로그인해야 해요.

`uzzint.github.io/gyomu/sheet`는 교무수첩과 연결된 구글 시트(교무수첩 데이터)로 이동해요. 시트도 내 계정만 열 수 있어요.

`uzzint.github.io/gyomu/class`는 학생·학부모용 **우리 반 알림** 앱이에요. 비밀번호(교무수첩 설정에서 정함)를 넣으면 공개로 둔 조·종례 공지, 학사일정, 제출물 마감, 우리 반 시간표가 보여요. 자료는 이 저장소에 없고, 열 때마다 '우리 반 알림' 앱스스크립트에서 받아 와요. 휴대폰에서 '홈 화면에 추가'하면 앱처럼 쓸 수 있어요.
